# سند ۰۲: معماری دسترسی بدون فیلتر در ایران (Anti-Filter Architecture)

## صورت مسئله
- دامنه‌های پیش‌فرض `*.pages.dev` و `*.workers.dev` شرکت Cloudflare در بیشتر اپراتورهای ایران (همراه اول، ایرانسل و مخابرات) مسدود (DNS Hijack یا SNI Blocking) هستند.
- اگر سایت روی دامنه فیلتر باشد، کاربر ایرانی بازدهی صفر خواهد داشت.

---

## راه‌حل‌های پایدار و ارزیابی آن‌ها

### راهکار اول: دامنه اختصاصی با IP تمیز کلادفلر (Clean IP / Anycast Direct)
- اتصال یک دامنه مجزا (مثلاً `.ir` یا دامنه بین‌المللی آزاد مثل `.shop` یا `.xyz`) به کلادفلر.
- ثبت رکوردهای DNS به همراه استفاده از پروکسی معکوس و IP تمیز کلادفلر که روی شبکه ایران پکت‌لاس ندارد.

### راهکار دوم: سیستم هیبریدی (Dual-Entry Fallback)
- **پایگاه اصلی:** ربات تلگرام (از آنجا که تلگرام در بستر پروکسی‌های اختصاصی ما که هر روز بروز می‌شوند کار می‌کند، هیچ‌وقت مسدود نیست).
- **وب‌اپلیکیشن درون تلگرام (Telegram Mini App / WebApp):** سایت در قالب یک تلگرام وب‌اپ بارگذاری می‌شود که می‌تواند از طریق ساب‌دامین‌های چرخشی یا پروکسی ورکر باز شود.
- **Static Edge Mirroring روی GitHub Pages / Vercel:** ساخت دو آدرس جایگزین موازی؛ اگر اپراتور یکی را بست، آدرس دوم فوراً در کانال تلگرام پین می‌شود.

---

## سوال و تصمیم باز برای شما:
آیا ترجیح می‌دهید یک دامنه مجزا (مثلاً `.ir` که در ایران فیلتر نمی‌شود، یا یک دامنه بین‌المللی ارزان) برای سایت ست کنیم، یا مایلید از راهکار وب‌اپلیکیشن تلگرام (Telegram WebApp) بدون وابستگی به فیلترینگ مرورگر استفاده کنیم؟
