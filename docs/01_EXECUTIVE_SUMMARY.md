# سند ۰۱: خلاصه اجرایی و مدل فروش اکانت و توکن AI

## ۱. محصولات قابل ارائه
1. **اکانت‌های اختصاصی / اشتراکی آماده:**
   - ChatGPT Plus (OpenAI)
   - Claude Pro (Anthropic)
   - Midjourney / Flux (تولید تصویر)
   - Perplexity Pro
   - GitHub Copilot / Cursor Pro
2. **فروش توکن و Reverse Proxy API:**
   - فروش کردیت دلاری/توکنی برای دسترسی مستقیم برنامه‌نویسان و پژوهشگران بدون نیاز به مسترکارت خارجی.

---

## ۲. کانال‌های ورودی مخاطب (Funnel)
- **کانال تلگرامی تخصصی AI:** روزانه اخبار داغ، مقایسه مدل‌ها، و پرامپت‌های شگفت‌انگیز را منتشر می‌کند؛ انتهای هر پست، لینک خرید لایسنس و اکانت با تخفیف قرار دارد.
- **ربات تلگرام فروشگاهی:** برای کاربرانی که بدون ترک تلگرام مایل به ثبت سفارش، استعلام موجودی و پشتیبانی هستند.
- **سایت سبک بر روی Cloudflare Pages:** ویترین تمیز، سریع و مدرن برای معرفی خدمات و سفارش سریع.

---

## ۳. کنترل پنل ادمین از طریق تلگرام
ادمین (با شناسه عددی مشخص) بدون نیاز به لپ‌تاپ یا پنل وب:
- قیمت هر محصول را تغییر می‌دهد: `/setprice chatgpt_plus 1450000`
- اکانت جدید اضافه می‌کند: `/addstock claude_pro user:pass:token`
- موجودی را می‌بیند: `/stock`
- گزارش درآمد ۲۴ ساعت اخیر را دریافت می‌کند: `/report`
